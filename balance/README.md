# Баланс «Расселины»

Все числа игры таблицами. Их можно читать и править прямо здесь, с телефона: GitHub даёт редактор на каждый файл.

## Как это работает

1. Правите число в клетке и коммитите — прямо в вебе.
2. На машине с проектом:

```
git pull
dart run tool/balance_sheet.dart --check   # что изменится
dart run tool/balance_sheet.dart --apply   # в JSON игры
cd app && dart run tool/sync_content.dart  # зеркало для APK
```

3. Проверить, во что это обошлось игре:

```
dart test                                   # правила игры целы
dart run tool/sim_cli.dart --curve           # где стена
dart run tool/sim_cli.dart --campaign 20     # шестьдесят спусков
dart run tool/audit_cli.dart --relics        # всё ли работает
```

## Правила таблиц

* Правится **только колонка со значением.** Имя, id и путь параметра — это адрес строки; поменяете их — правка не найдёт, куда лечь.
* Пустая клетка значит «этого параметра у сущности нет». Оставьте её пустой.
* Дробная часть — через точку или запятую, обе понимаются. Список чисел в одной клетке разделяется запятой с пробелом.
* Строки можно переставлять, между таблицами — дописывать свои заметки. Разбирается только то, что размечено маркером `<!-- balance: ... -->`; его трогать не надо.
* `--apply` либо применяет ВСЁ, либо не пишет ничего: сначала он собирает правки, потом проверяет получившийся контент целиком, и только чистый контент попадает на диск.

## Чего здесь нет

Не-числовых полей: тегов умений, видов вещей, эффектов реликтов, текстов. Это не баланс, а устройство контента — и правится оно в `assets/content/*.json` вместе с кодом, который их читает.

Файлы этой папки собраны `tool/balance_sheet.dart`. Править их руками — можно и нужно; переписывать по кругу `--export` тоже безопасно: он выводит их из того же контента.
