# Расселина

Idle-RPG: вы не спускаетесь в бездну сами — вы нанимаете тех, кто спускается.
Наёмник уходит вниз с той сборкой, которую вы ему собрали, и идёт, пока не
погибнет. Гибель не проигрыш: снаряжение, золото и Эхо возвращаются на Заставу,
теряется только глубина.

Android, Flutter + Flame. Русский язык.

## Устройство репозитория

```
lib/core/      ядро игры: чистый Dart, ни одного импорта Flutter
assets/content/  весь баланс — JSON, который читает ядро
app/           Flutter-клиент (пакет rift_app, подключает ядро по пути)
balance/       те же числа таблицами, чтобы править их с телефона
docs/          дизайн-документ, решения, роадмап, справочники
tool/          балансировщик, аудит контента, генераторы
test/          492 теста ядра (app/test — ещё 155 на экраны)
```

**Правило, на котором всё держится:** ни одной игровой формулы вне
`lib/core`. Клиент только показывает то, что посчитало ядро, а ядро считается
без Flutter — потому и проверяется симуляциями на тысячи спусков, а не глазами.

**Второе правило:** ни одного числа баланса в коде. Всё, что можно
покрутить, лежит в `assets/content/*.json` и проверяется при загрузке;
игра с битым контентом не стартует.

## Запуск

```bash
dart test                         # ядро
cd app && flutter test            # экраны
cd app && flutter run -d android  # игра
```

## Баланс

Числа правятся в таблицах, а не в JSON — в том числе с телефона, прямо на
github.com. Как это устроено: [balance/README.md](balance/README.md).

```bash
dart run tool/balance_sheet.dart --check   # что изменилось в таблицах
dart run tool/balance_sheet.dart --apply   # применить в игру
```

Посмотреть, во что правка обошлась:

```bash
dart run tool/sim_cli.dart --curve      # где стена
dart run tool/sim_cli.dart --campaign 20  # шестьдесят спусков подряд
dart run tool/audit_cli.dart --relics   # каждый реликт ещё меняет исход?
```
