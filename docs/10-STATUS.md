## Что в игре

* **Спуск.** Наёмник идёт вниз сам и погибает; снаряжение, золото и Эхо
  возвращаются. Верёвка с 15 % рекорда. Живые развилки с третьим путём для
  присутствующего; ожидание 45 с при игроке, 10 минут без него. Разлом дня.
* **Смена у Костра** (новое). Нанятые заранее сменщики уходят вниз в секунду
  гибели предыдущего и в его сборке; без игрока — по приказу и без стояния на
  развилках. Места — по одному на слот с Костра 2, 5 и 8. Одно уведомление на
  конец всей смены.
* **Сборка.** 9 слотов, 4 слота умений (55 умений), 25 реликтов, осколки
  аффиксов, перекат и углубление в Кузнице.
* **Застава.** 8 построек по 8 уровней, уровень открывает глубина. Второй
  слот спуска с Таверны 4-го уровня.
* **Прогрессия.** Древо Эха (22 узла) и за ним **Отзвук глубины** (новое:
  +0.5 % силы за уровень, каждый вдвое дороже), дерево пассивок (300 узлов),
  Клеймо Бездны до 30-го ранга, 44 задания.
* **Поздний этап — логова стражей.** С рекорда 150 — четыре стража с
  бесконечной лестницей кругов, подношение, гибель проигравшего, умения с
  замахом, бой на экране. **Своя мощь у каждого стража** (новое): Громовой
  ×3.5, Пепельный и Пустотный ×5, Ледяной ×5.5.
* **Аккаунт.** Анонимный вход Firebase, облачное зеркало сейва со сверкой
  конфликтов, сезон в адресе сейва, миграции сейва до **7-й** версии
  (смена и Отзвук). Аналитика Firebase, новые события `relay_queued` и
  `relay_takeover`.

## Что сделано в раунде 40

1. **Замер открытых тревог.** Золото на рубеже — ложная тревога: запас
   держится на 1.0–1.5 задатка Легенды всю кампанию. Мощь ×3 уже не держала
   стражей. Черты и умения на позднем этапе стоят ноль этажей.
2. **Смена у Костра** (GDD §9.4) — офлайн-догон, ROADMAP §2.3.
3. **Отзвук глубины** (GDD §8.3.1) — сток Эха за выкупленным древом. Первые
   числа дали +38 % рекорда; подобраны сеткой до +0.6…+8.6 %.
4. **Логова:** проба переписана (общий круг у рекорда, четыре сборки), своя
   мощь у каждого стража.
5. **Инструменты:** `--daily` (сутки игрока со сменой), `--traits` (черты и
   ранги), `--set` (число баланса на один прогон), колонка «запас» в
   `--campaign`.

## Открыто — дизайн и баланс

* **Урон на позднем этапе решает мало** (раунд 41). Волны по-прежнему гибнут
  с одного удара; проверку урона взял на себя босс бездны (здоровье по кривой
  вещей, мощь ×8 к 300-му этажу, ярость с третьей секунды), взрыв и отражение
  пошли через защиту. Броня, сопротивления и скорость атаки теперь двигают
  глубину, но урон ×2 даёт лишь +0.5…+1.7 этажа против +4…+5 у здоровья.
* **Бой у рубежа решают проценты силы.** Прибавка в одну десятую переводит бой
  стража без ответа из 0/9 в 7/9. Своя мощь стражей держит замысел в среднем
  по сидам, а не на каждом.
* **Темп контента со сменой.** Сотый контракт на 7–9 день вместо третьей
  недели у игрока с четырьмя заходами. Места в смене открываются рано
  (Костёр 8 — рекорд 96). Пересматривать по `relay_takeover`.
* **Прогноз смены на телефоне.** `RelayForecast` копирует профиль через сейв и
  досчитывает всю смену в UI-потоке — при уходе в фон и при каждой правке
  очереди. На ПК это доли секунды; на слабом телефоне не мерено.
* **Сезоны** — второй слой позднего этапа. В сейве есть только адрес сезона.
* **Ожидание на развилке без игрока — 10 минут** для контрактов, отправленных
  руками. Сменщики, ушедшие без игрока, не стоят вовсе.

## Как проверить самому

```
dart test                                            # ядро
dart run tool/audit_cli.dart --bosses                # стражи опасны, проходимы, разные
dart run tool/sim_cli.dart --campaign 150            # длинная дистанция, запас золота
dart run tool/sim_cli.dart --lair-probe 120          # тяжесть круга у рекорда
dart run tool/sim_cli.dart --daily 14                # сутки игрока со сменой 0..3
dart run tool/sim_cli.dart --traits 60               # черты и ранги в глубине
dart run tool/sim_cli.dart --campaign 150 --set curves.echoResonancePower=0
cd app && flutter test                               # приложение
```

Логова открываются с рекорда 150, смена — с Костра 2-го уровня. Для ручной
проверки на эмуляторе сейв ветерана подкладывается в
`/data/data/com.riftgame.rift_app/app_flutter/rift.save.json` через
`adb shell run-as` (отладочная сборка); сейв 6-й версии мигрирует в 7-ю сам.
Если процесс исчез без записи в `adb logcat -b crash`, причину называет
`adb shell dumpsys activity exit-info com.riftgame.rift_app`.
